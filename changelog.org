#+TITLE: changelog.org
#+DESCRIPTION: Update tracking for MCQ Quiz (Mobile PWA)

Companion project to [[file:../../mcq-quiz-generator-desktop/changelog.org][mcq-quiz-generator-desktop]].

* v0.3.0 - 2026-09-11
  Three quiz modes, answer locking, code refactoring.
  - [X] *Three quiz modes:* Loop (retakes wrong answers, instant feedback),
        Instant (instant feedback, no loop), Classic (deferred feedback, results page)
  - [X] *Removed instantFeedback setting:* feedback behavior now determined by mode
  - [X] *Answer locking:* in Loop and Instant modes, option buttons are disabled
        after answering to prevent cheating
  - [X] *Code refactoring:* extracted =format.ts= (shared =formatTime=, =escapeHtml=,
        =LABELS=), deduped =exactMatch= via =Matchable= interface, removed dead code
        from mcqParser/main.tsx/quizExporter
  - [X] *CSS fixes:* added =.topbar-actions=, replaced hardcoded colors with CSS
        variables, removed =!important= specificity hack, added =.tag-instant= class
  - [X] *Removed Clear button* from history section
  - [X] README.org, plans-and-todos.org, changelog.org updated

* v0.2.0 - 2026-09-08
  Loop mode, settings panel, keyboard shortcuts, quality-of-life.
  - [X] *Loop mode:* retakes wrong answers in batches of 15 until all mastered;
        instant feedback forced on; no results page
  - [X] *Mode picker overlay:* choose Loop or Normal mode before each quiz
  - [X] *Settings panel:* gear button in topbar opens modal with Instant Feedback,
        Randomize Options, Randomize Question Order toggles
  - [X] *Keyboard shortcuts:* a/b/c/d (select), n/p (next/prev), j/k (scroll),
        Esc/q (leave) -- for students on laptop/PC
  - [X] *Last opened file hint:* shows filename of last opened exam on home screen
  - [X] Extracted =quizModes.ts= (grading + loop logic) + unit tests (23 total)
  - [X] Renamed =plan-todos.org= -> =plans-and-todos.org=
  - [X] README.org updated: rich .mcq examples (LaTeX, code), new features documented

* v0.1.0 - 2026-08-31
  Initial mobile PWA -- fully offline student quiz taker.
  - [X] Vite + React 19 + vite-plugin-pwa scaffold
  - [X] Ported parser, renderRichText, quizLogger, quizExporter, shuffle from desktop
  - [X] WebCrypto AES-GCM .emcq decrypt (interop-verified against desktop fixtures)
  - [X] Import via in-app file picker (.mcq, .emcq, .txt, .md, .org)
  - [X] Quiz UI: radio/checkbox cards, timer, instant feedback, leave button
  - [X] Results: score, per-question review with Your/Correct Answer(s)
  - [X] PDF export via window.print() on self-contained HTML
  - [X] Local quiz history (localStorage) with clear option
  - [X] SettingsContext (localStorage, dark/light, instantFeedback, shuffle)
  - [X] PWA: manifest, service worker precache, auto-update, icons
  - [X] 16 unit tests passing (parser, exporter, crypto interop)
  - [X] TypeScript typecheck clean (app + vite config)
